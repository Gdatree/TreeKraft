**TreeKraft** — консольный язык программирования с ASCII-графикой, встроенным игровым движком и REPL.  
Работает без Python, без внешних зависимостей. Всё в одном `.exe`. Код открыт — никаких троянов.

## Возможности

| Категория | Что умеет |
|-----------|-----------|
| **REPL** | Интерактивный ввод команд, история, справка по темам (`help math`, `help strings`) |
| **Многострочный ввод** | `if/else/end`, `while/end`, `for/end`, `loop/break/continue`, `try/catch` |
| **Функции** | `~def name(params), body`, `~call`, `~return` |
| **Математика** | `sin`, `cos`, `atan2`, `sqrt`, `log`, `exp`, `clamp`, `pi`, `e`, `randf` |
| **Строки** | Интерполяция `"Hello {name}"`, `~upper`, `~lower`, `~split`, `~replace`, `~find` |
| **Списки** | `~list`, `~add`, `~get`, `~set`, `~remove`, `~sort`, `~rev`, `~len` |
| **Словари** | `~dict`, `~dset`, `~dget`, `~dhas`, `~dkeys`, `~dvals`, `~ddel` |
| **ASCII-дисплей** | `~ldsc`, `~ldbox`, `~ldm` (линии), `~ldtext`, `~ldshow`, `~ldclear` |
| **KGame** | `kg.rect`, `kg.circ`, `kg.pixel`, `kg.text`, `kg.key`, `kg.update` |
| **Файлы** | `~read`, `~write`, `~append`, `~readlines`, `~dir`, `~mkdir`, `~cp`, `~mv`, `~fsize` |
| **Конфиги .dtam** | `~dcfg set/get/del`, `~save`, `~load` |
| **Система** | `~run`, `~exec`, `~env`, `~sysinfo`, `~timer`, `~trace`, `~args` |
| **Карты и объекты** | `~map`, `~obj`, `~objmove`, `~spawn`, `~showmap`, `~loadmap` |
| **Анимация** | `~cm` (анимированный текст), `~melody`, `~beep` |
