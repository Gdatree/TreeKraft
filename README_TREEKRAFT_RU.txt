ПРИМЕРЫ СКРИПТОВ

Приветствие (hello.tk):

    ~green(=== ПРИВЕТСТВИЕ ===)
    name = ~in("Как тебя зовут? ")
    tx("Привет, {name}!")
    ~wait2
    ~red(До свидания!)

Игра "Угадай число":

    ~green(Угадай число от 1 до 10)
    secret = ~rnd(1, 10)
    while 1 == 1 do
        guess = ~in("Твой ответ: ")
        if guess == secret then
            ~green(Победа!)
            break
        else
            if guess < secret then
                ~yellow(Больше)
            else
                ~yellow(Меньше)
            end
        end
    end

Пример ASCII-игры:

    ~ldsc(40, 20, "#", ".")
    x = 5
    y = 5
    while 1 == 1 do
        key = ~key()
        if key == "w" then y = y - 1 end
        if key == "s" then y = y + 1 end
        if key == "a" then x = x - 1 end
        if key == "d" then x = x + 1 end
        ~ldc(x, y)
        ~ld(x, y, "@")
        ~ldshow()
    end

ЧАСТЫЕ ОШИБКИ

  "Unknown command"
    → Проверь правильность написания команды
  "Not found"
    → Переменная не объявлена. Используй ~exists() для проверки
  "Не число"
    → Математические операции требуют числа. Проверь через ~type()
  "Индекс вне диапазона"
    → Индекс выходит за границы списка
  "Файл не найден"
    → Файл не существует. Проверь путь
